PROJECT TITLE: 
API CALL

SHORT DESCRIPTION:
THIS PROJECT SHOWS HOW API WORKS USING POSTMAN.

SETUP INSTRUCTIONS:
STEP 1. OPEN VSCODIUM AND OPEN THE LARAVEL PROJECT

STEP 2. OPEN THE SERVER IN TERMINAL WITH php artisan serve

STEP 3. OPEN POSTMAN

STEP 4. COPY THE LINK SERVER http://127.0.0.1:8000 THEN ADD api/students "http://127.0.0.1:8000/api/students"

STEP 5. CLICK THE "NEW" IN LEFT SIDE AND CLICK THE HTTPS

STEP 6. PASTE THE "http://127.0.0.1:8000/api/students" IN "GET" THEN SEND

STEP 7. CHANGE THE GET INTO POST THEN GO TO BODY - RAW - JSON THEN ADD A DATA YOU WANT TO ADD, FOR EXAMPLE; {
  "name": "Mikko A. Catinguel",
  "course": "BSIT"
}

STEP 8. CHANGE THE POST INTO PUT AND PASTE THE "http://127.0.0.1:8000/api/students" AND ADD THE ID OF THE STUDENT, FOR EXAMPLE; "http://127.0.0.1:8000/api/students/1" THEN EDIT YOU WANT TO EDIT AND SEND

STEP 9. CHANGE THE PUT INTO DELETE THEN CLICK THE SEND
